What does this expect & produce?

Input — a CSV with the CelesTrak GP/OMM header (OBJECT_NAME, OBJECT_ID, EPOCH, MEAN_MOTION, ECCENTRICITY, INCLINATION, …, NORAD_CAT_ID, …). Get one at celestrak.org (choose CSV as the format).

Output — a standard NORAD two-line element file with the same name as the input, only the extension changes (e.g. stations.csv → stations.txt). The default .txt opens straight in your text editor; switch to .tle above if a downstream tool expects that extension.
