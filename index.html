CelesTrak OMM / CSV format
What does this expect & produce?

Input — a CSV with the CelesTrak GP/OMM header (OBJECT_NAME, OBJECT_ID, EPOCH, MEAN_MOTION, ECCENTRICITY, INCLINATION, …, NORAD_CAT_ID, …). Get one at celestrak.org (choose CSV as the format).

Output — a standard NORAD 3-line TLE file, saved with the same base name and a .tle extension (e.g. stations.csv → stations.tle).

Runs 100% offline in your browser · open-source · files save to your browser's download location
